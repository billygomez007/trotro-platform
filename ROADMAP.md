# Roadmap

## Phase 0 — Architecture
Repository standards, architecture, schema, API contracts, security, CI/CD and ADRs. No rushed UI coding.

## Phase 1 — Platform Core
Authentication, profiles, organizations, roles/permissions, payment abstraction, notifications, location abstraction, analytics and audit.

## Phase 2 — Mobility Core
Routes, stops, vehicles, drivers, operators, schedules, trips, seats and bookings.

## Phase 3 — Booking
Night-before booking, same-day live booking, segment seat inventory, payment, cancellation and lifecycle.

## Phase 4 — Live Mobility
GPS, live location, ETA, route matching, nearby relevant vehicles and approaching-stop alerts.

## Phase 5 — Operator System
Fleet, driver management, schedules, trip management, analytics and revenue.

## Phase 6 — Pilot
Controlled Kasoa -> Accra launch with real operators, vehicles, drivers, stops and passengers.

## Phase 7 — Scale
Expand routes/cities only after operational metrics prove the model. Future verticals remain separate roadmap decisions.
